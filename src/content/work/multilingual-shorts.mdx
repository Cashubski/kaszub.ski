## The hypothesis

Does a short-form educational format transfer between languages, or does each audience need its own? I built a pipeline to find out: one concept goes in, and two localised videos come out, an English one for CleverFacts and a Polish one for Ogarnik. The channels share localised versions of the same underlying concepts; that is the design of the experiment.

Over ten days in March 2026 the pipeline published {a.en.experiment_videos} videos on each channel. Six months later I exported the full analytics history of both and analysed it. This page reports what the data supports, and says where it stops.

## What I built

- An automated production pipeline. The videos were generated through APIs, not edited by hand: one concept becomes a vertical video with a voice.
- A localisation stage. Each concept is translated and adapted for the Polish audience, then dubbed expressively, so the delivery survives the change of language.
- Two channels run as a matched set: the same format, the same concepts, published in nearly the same order within the same ten days, so that a concept can be read across markets.
- Editorial choices: topic selection, hooks, pacing and publishing cadence.
- A measurement stage: an export of each channel's full history through the YouTube APIs, an analysis script that reduces it to aggregates, and the charts on this page, which are drawn from that file when the site is built.

I did not build or train the generation models. They are reached through their providers' APIs. My work is the pipeline around them, the two channels it produced and the analysis that measures them.

## Technical stack

The pipeline is built on three groups of interfaces: video generation, voice and dubbing, and the YouTube APIs for measurement.

<div class="table-wrap" role="region" aria-label="Technical stack by layer" tabindex="0">

| Layer | Component | What it does |
| --- | --- | --- |
| Concept | Topic, hook and script | One educational idea per video, written for a short vertical format |
| Video | Google Veo (Vertex AI; Flow is the same model family's studio tool) | Generates the vertical footage as a long-running operation: a `predictLongRunning` request on the model, polled with `fetchPredictOperation` until the video is ready |
| Voice | ElevenLabs API, `POST /v1/text-to-speech/{voice_id}` | Narration for the English version |
| Localisation | ElevenLabs API, `POST /v1/dubbing` | Translates the video and dubs it into Polish, keeping the expressive delivery |
| Publication | Two YouTube channels | The English video goes to CleverFacts, the Polish one to Ogarnik |
| Export | YouTube Data API v3 and YouTube Analytics API v2, OAuth 2.0, Python | The upload index, then daily, per-video, country, traffic-source, device and audience reports, written to CSV per channel |
| Analysis | Python over the CSV exports | Restricts to the experiment's videos, matches the pairs, computes medians, shares and correlations, and writes one aggregates file |
| Presentation | Astro, inline SVG | Every chart on this page is drawn from the aggregates file at build time, with no chart library and no request to a third party |

## Limitations and status

Both channels are published, and nothing new has gone out since March 2026. The analysis is observational. The two channels have different audiences and sizes of market, the platform's distribution decides most of what any single video receives, and a concept was published once per language, so no pair is a controlled comparison. A correlation of {a.pairs.spearman} across {a.pairs.n} pairs, with an interval of roughly {a.pairs.spearman_ci95[0]} to {a.pairs.spearman_ci95[1]}, is evidence of a loose relationship and nothing finer. Pairs were matched by hand from the titles and the publication order.

Views count plays, not people. Per-video audience retention curves are not part of this export: that report needs one request per video and the run stalled, so the page relies on average percentage viewed and makes no claim about where in a video viewers left. Traffic source, device, country, age and gender are channel-level reports and cannot be split by video. The API has no hour-of-day dimension, so nothing here speaks to publishing time.

The production code is not public, and this page describes that side of the pipeline by layer and interface only. The generation models belong to their providers and I make no claim about them.

## What I learned

<div class="offset">

<p class="pull">A format can transfer between languages while the hits do not.</p>

The same pipeline produced a working channel in both markets, with the same launch curve, the same dependence on the feed and the same television audience. Which concepts took off was a different matter in each language, and the Polish channel's result rested on three videos about pets. If I ran it again I would publish fewer concepts more than once, so that the difference between a concept and a lucky day could be measured, and I would judge each video on its first week, because the data says there is no second one.

On the engineering side: once production was automated, measurement became the part still to build. The charts on this page are the end of that pipeline, and they redraw themselves from a new export.

</div>
